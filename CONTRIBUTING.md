# Contributing to OrderSift

Thanks for your interest in helping improve OrderSift — contributions of all
kinds are welcome: bug reports, feature requests, documentation fixes,
examples, tests, and pull requests.

## Code of Conduct

Be respectful and constructive. If you'd like a formal policy added (e.g.
Contributor Covenant), open an issue and I can add it.

## Getting started (local development)

1. Fork the repository and clone your fork:

   git clone https://github.com/<your-username>/OrderSift.git
   cd OrderSift

2. Install dependencies:

   npm install

3. Start the dev server:

   npm run dev

4. Open the app in your browser:

   http://localhost:3000

## Branching & commits

- Create a topic branch from `main`: `git switch -c feature/short-description` or
  `fix/short-description`.
- Keep commits small and focused. Write clear commit messages in the
  imperative present tense (e.g. "Add CONTRIBUTING.md").
- Rebase or squash commits before merging when appropriate.

## Pull request process

1. Open a pull request against the `main` branch.
2. Describe what you changed and why. Include screenshots or examples for UI
   changes.
3. Link related issues using `fixes #<issue-number>` when applicable.
4. At least one approving review is required before merging.

If you plan a large or breaking change, consider opening a draft PR to get
early feedback.

## Tests & linting

- Run linters and formatters before submitting: `npm run lint`.
- Add unit or integration tests for bug fixes and new features when
  reasonable.

## Reporting issues

When opening an issue, please include:

- A short, descriptive title
- Steps to reproduce (or a minimal example)
- Expected vs actual behavior
- Environment details (Node version, browser) if relevant

## Documentation & examples

- Update README.md, add examples, or include screenshots/GIFs for UI
  changes.
- Add short usage examples for new features where helpful.

## Maintainers & getting write access

If you'd like to become a contributor with write access, open an issue and
explain how you'd like to help (areas, time commitment, prior contributions).

---

Thanks again — your contributions help small businesses spend less time on
paperwork and more time doing what they love.
